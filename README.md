# Что посмотреть?

Личный каталог фильмов на русском языке. Адаптивный сайт без зависимостей и этапа сборки.

## Возможности

- 12 фильмов с постерами и описаниями.
- Поиск по названию и режиссёру, фильтр по жанру.
- «Выбери за меня»: до трёх фильмов с учётом жанра, настроения, свободного времени и просмотренного.
- Список на будущее и отметки о просмотре сохраняются в localStorage текущего браузера.

## Публикация на GitHub Pages

Статическая версия подготовлена в `docs/`.

1. Откройте Settings → Pages в репозитории.
2. В Build and deployment выберите Source: Deploy from a branch.
3. Выберите ветку main и папку /docs, затем Save.
4. Дождитесь завершения публикации. Адрес сайта появится на странице Pages.

После изменений в public/index.html обновляйте также docs/index.html.

## Публикация на Vercel

1. Импортируйте этот репозиторий в Vercel через Add New → Project.
2. Framework Preset: Other; Root Directory: корень репозитория.
3. Этап сборки не нужен. Output Directory: public (указано в vercel.json).
4. Нажмите Deploy.

## Локальный запуск

Откройте public/index.html в браузере или запустите любой статический сервер для папки public.

## Ограничения

Это статическая версия: авторизация по почте и синхронизация между устройствами ещё не реализованы. Маршруты входа ChatGPT относятся к прежней платформе размещения и в эту версию не включены. Для email-входа потребуется подключить провайдера авторизации и серверное хранилище.

Подборка основана на выбранных параметрах и стартовом каталоге; она не использует актуальные афиши и данные стриминговых сервисов. Постеры загружаются с TMDB, шрифты — с Google Fonts, поэтому для них требуется интернет.
